**Vektorgeist** builds locally-sovereign AI: systems that run on the user's own hardware, with
deterministic, auditable components wherever a trained model isn't actually needed.

**The thesis.** The industry defaults to "rent a giant model for everything." A measurable class
of capability — recognition, retrieval, continual learning, verification — can run with no
trainable weights, no GPU, no cloud, and no forgetting, on hardware people already own. We've
published the method (4 open-access papers, permanent DOIs) and shipped working products on it.

**Proof, not promises.**
- Published series: learning with 5–10× less data than a matched network; zero catastrophic
  forgetting *by construction* (order-invariance measured at 1.000); training-free prediction
  beating a trained network 3–16×. All results emitted by released scripts.
- A public study record with retractions kept visible — diligence-friendly research hygiene.
- Shipped: magpie-search (federated transcript/file search, PyPI + npm + MCP registry),
  warden (local-first MCP gateway), Aviary (local security suite), Pallium (self-hostable
  private-AI stack, NLnet grant application in review).

**Why now.** Local-first AI is becoming a procurement requirement (privacy, cost, sovereignty).
The pieces we ship — gateway, memory, retrieval, verification — are the infrastructure layer of
that shift, and they're already written.
